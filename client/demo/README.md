# Brake on EVM: technical demo

Live (Base Sepolia): https://usebrake.vercel.app

The nine-step Brake story running on real contracts with your own browser wallet. Brake's side is real
transactions; the plain "Without Brake" wallet is simulated for comparison and labelled so. Amounts
are dUSD, a test dollar with 6 decimals, like USDC.

Runs on **Base Sepolia** (deployed 2026-10-12) or a local Anvil chain, picked with `VITE_EVM_NETWORK`
in `.env` (`base-sepolia` or `anvil`, the default).

Base Sepolia addresses (`src/chains/evm/networks/base-sepolia.json`):
Brake `0x374c62ff03E24F61B86CAACB0721bf3C854695e3`, dUSD `0x61B1e0336E6949EdAEea5408EE1A1175A83c6326`,
DemoWorld `0x5937F7AaD8F4Da4c203781DAb156e0Fe9E34f8D9`. All three verified on Basescan
(https://sepolia.basescan.org/address/0x374c62ff03E24F61B86CAACB0721bf3C854695e3#code).

## Run it (local Anvil)

In three terminals, from `client/demo` (Foundry installed; run the contract setup in
[contracts/brake](../../contracts/brake/README.md#run-the-tests) once first):

```sh
npm install
cp .env.example .env   # then set VITE_EVM_NETWORK=anvil for the local chain
npm run chain    # Anvil, one block per second
npm run setup    # deploys Brake, dUSD and the DemoWorld factory; writes src/chains/evm/networks/anvil.json
npm run dev      # open the URL Vite prints
```

**Wallets: Reown.** "Connect your wallet" opens Reown's picker: browser extensions, phone wallets by
QR code (so a real phone can play "your phone"), and 100+ others. It needs `VITE_REOWN_PROJECT_ID` in
`.env` (public; see `.env.example`). Without it, the page uses the best browser extension: MetaMask,
then Phantom, then any other. On testnets, reads also go through Reown's RPC first, with the chain's
public RPC as the fallback (Base Sepolia's often answers 401 to browsers). The page adds the Anvil network
(chain 31337) to the wallet if needed and gives the connected account local ETH.

1. **Connect your browser wallet.** It plays you: the account's owner, and "your phone".
2. **Set up the demo** (one approval). `DemoWorld.create` makes a new smart account you own,
   installs Brake, mints 20,000 dUSD into it, trusts Alex, and sends the agent and watcher a little
   ETH for gas if they're low.
3. Follow the story. Adding Sam and cancelling the payment are approvals in your wallet; the rest is
   done by the demo's agent and watcher.

On Anvil, "Ignore it" on step 8 skips time past the hold, so both endings work.

**Replay reuses your wallet, with no approval.** The agent cancels anything the last run left waiting,
tops the account back up to 20,000 dUSD from the open faucet, and the story gets a new Sam and
attacker (so Sam starts untrusted). A new wallet is set up only when today's instant budget
(500 dUSD) is spent, after about five replays, or when you pick "Start over with a new wallet".

## Base Sepolia

`VITE_EVM_NETWORK=base-sepolia` in `.env` switches the demo to Base Sepolia (Basescan links, no time
skip, so only the "Cancel it" ending). The shared contracts are already deployed; to redeploy (it
rewrites `src/chains/evm/networks/base-sepolia.json`):

```sh
cd ../../contracts/brake
NETWORK=base-sepolia forge script script/DeployDemo.s.sol --rpc-url https://sepolia.base.org --broadcast --account <keystore>
bash ../../client/demo/scripts/abis.sh
```

Costs at 0.01 gwei: the deploy about 0.0001 ETH; each setup sends 0.00003 ETH each to the agent
and watcher (about ten transactions each), only when they're low.

In **Phantom**, turn on Settings → Developer Settings → Testnet Mode first: Phantom doesn't let sites add
networks, so the page can only ask it to switch to Base Sepolia.

## Who holds which key

| Role | Key | Where it lives |
|---|---|---|
| You (owner) | Owner of the `DemoAccount` | Your wallet |
| Your phone | Brake key that may cancel | Your wallet |
| Agent | Driver key | Generated in this browser at runtime |
| Watcher | Brake key, hold only | Generated in this browser at runtime |

The agent and watcher keys stay in this browser's storage. Fine for test networks; never for real funds.

## What runs where

- `src/chains/evm.ts`: the adapter (propose, preview, trust, hold, cancel, execute, reads). Network
  settings are at the top.
- `src/chains/evm/wallet.ts`: the browser wallet over EIP-1193, found through EIP-6963.
- `src/chains/evm/abis.ts`: generated by `npm run abis` from Foundry's build. Don't edit.
- Contracts: [../../contracts/brake/src](../../contracts/brake/src). `DemoWorld` and `DemoAccount` are demo-only.
- Chain wording comes from the adapter; `App.tsx` stays chain-neutral.

## Testing without a wallet extension (development only)

Put a throwaway key in `.env.local` (gitignored) as `VITE_DEV_WALLET_KEY=0x…`, and `npm run dev`
registers a stand-in wallet that signs with it, only in a browser where `localStorage["brake-dev-wallet"]` is `"on"` (so your own browser always uses your real wallet). On Anvil, its public default key #0 is fine. Never
put keys in URLs or commits.
